# Ticket Max — Emanuel

Proyecto Java con una interfaz de consola para administrar usuarios en memoria.

## Ejecutar

Usa un JDK 25 o superior. En IntelliJ IDEA ejecuta `src/main/java/app/Application.java`. Introduce **1** para iniciar y **2** para entrar al menú de usuarios.

El menú permite registrar, consultar por ID, listar, actualizar, eliminar y contar usuarios. Los datos se pierden al cerrar la aplicación.
